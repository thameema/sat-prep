# Digital SAT Mastery Hub & Live AI Coach
**Target Score: 1450+ | Exam Date: December 5, 2026**

An interactive, responsive Digital SAT testing and coaching platform modeled directly after College Board's official **Bluebook** application. Built with an embedded Desmos Graphing Calculator, instant answer diagnosis, and a live AI coaching assistant.

---

## Features
- **25 High-Yield Curated Questions:** 12 Reading & Writing and 13 Math questions targeting both standard modules and Hard Module 2 archetypes.
- **Embedded Desmos Graphing Calculator:** Floating, draggable, and resizable modal matching the Bluebook interface, with one-tap equation loading.
- **Real-Time AI Coach:** Live coaching assistant that provides step-by-step guidance, identifies College Board traps, and gives 10-second Desmos shortcuts.
- **Multi-Device Responsive:** Works on desktop, laptop, iPad, and mobile phones with touch-friendly navigation.
- **Two Practice Modes:**
  - *Tutor Mode:* Instant feedback, rationale, and Desmos shortcuts after each answer.
  - *Exam Simulation Mode:* Strict 35-minute countdown timer with zero hints.
- **Official Math Reference Sheet:** Built-in modal with all formulas provided on the real Digital SAT.
